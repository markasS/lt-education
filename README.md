# Литовский язык — практика грамматики

Личный учебный сайт. Первая тема: регулярные существительные на `-as` в единственном числе, все семь падежей. Задания и названия падежей на русском и литовском.

## Работа с сайтом

Ответы автоматически сохраняются в браузере. После завершения скачайте JSON и отправьте его на проверку. История завершённых попыток позволяет повторно скачать ответы. Новая попытка не меняет предыдущую. Правильность на сайте не оценивается; счётчик показывает заполнение. Данные не отправляются на сервер. При очистке данных браузера или смене устройства локальная история недоступна — сохраняйте скачанные файлы.

## Добавление занятий

`docs/lessons.json` содержит массив `lessons`. Добавляйте новый объект с уникальным `id`, `version`, названием, неделей, днём, словарём, падежами и блоками заданий. Новый объект появится в выборе занятий. При изменении заданий уже опубликованного занятия увеличивайте `version`: это сохраняет старый черновик под отдельным ключом. Не меняйте идентификаторы и версии опубликованных попыток задним числом.

Каждое занятие содержит `sections`: `reference` с учебными моделями, `table` с идентификаторами клеток или `questions`. У задания указаны `id`, `word`, `number` (sg/pl), `model`, `chooseCase`; для заданного падежа — `case`, для контекста — `sentence` и перевод. Публичные контекстные задания не содержат правильных ответов. Идентификаторы, версия и содержимое заданий понедельника сохранены; изменён только интерфейс и способ описания блоков. Проверочные ключи в локальном `materials/` отделены от сайта и не публикуются в репозитории; ответов к контекстным заданиям в браузерных данных нет. Памятка содержит учебный образец склонения. Вторник: множественное число -as и повторение единственного. Среда: оба числа -as и отдельное введение -a единственного числа (V., K., G., Vt.). Четверг: полная модель -a единственного числа, семь падежей (52 ответа, ориентир 60 минут). Пятница: полная модель -a множественного числа, семь падежей, повторение -as и упражнение по комиксу (66 ответов, ориентир 75 минут). Следующие занятия готовятся по результатам.

## Публикация

GitHub Pages публикует только каталог `docs/` из ветки `main`. Новые изменения в нём автоматически обновляют сайт после push в `main`. В настройках репозитория Pages выбран источник Deploy from a branch, ветка main, папка /docs. `.nojekyll` отключает обработку Jekyll — сборка приложения не нужна.

Локальный просмотр: запустить `python3 -m http.server 8765 --directory docs`, открыть `http://localhost:8765`. Не открывать HTML напрямую как файл: хранение в браузере и загрузка JSON требуют HTTP.

## Ответы и проверка

Экспорт schemaVersion 2 содержит тему, версию задания, инструкции, исходные ответы по номерам, выбранные падежи, число и модель склонения. Чекбоксов, объяснений и самооценки нет. Ранее завершённые попытки schemaVersion 1 сохраняются без изменений. `evaluation` остаётся `null` до проверки. Время означает длительность открытой страницы, включая паузы. Файлы ответов и проверки хранить в игнорируемом каталоге `results/`, а не в публичном репозитории.

## Варианты упражнений

`options` у вопроса заменяет свободный ввод выбором формы, сохраняя обычное поле `value` в экспорте. Блок `picture` содержит `image` (`src`, `alt`, `description`) и вопросы с `wordOptions`, `panel`; для таких вопросов `word` равен null, потому что нужное слово определяется по картинке. Экспорт сохраняет варианты слов, кадр и текстовое описание сцены для последующей проверки. Иллюстрация находится в `docs/assets/friday-comic.png`; её можно открыть крупнее. Текстовая альтернатива доступна отдельно.

Новые темы представляются полной регулярной моделью во всех семи падежах. Единственное и множественное число изучаются в отдельных занятиях. Старые уроки и их идентификаторы не меняются. Памятки не охватывают исключения и ударение.
