# Литовский язык — практика грамматики

Личный учебный сайт. Первая тема: регулярные существительные на `-as` в единственном числе, все семь падежей. Задания и названия падежей на русском и литовском.

## Работа с сайтом

Ответы автоматически сохраняются в браузере. После завершения скачайте JSON и отправьте его на проверку. История завершённых попыток позволяет повторно скачать ответы. Новая попытка не меняет предыдущую. Правильность на сайте не оценивается; счётчик показывает заполнение. Данные не отправляются на сервер. При очистке данных браузера или смене устройства локальная история недоступна — сохраняйте скачанные файлы.

## Добавление занятий

`docs/lessons.json` содержит массив `lessons`. Добавляйте новый объект с уникальным `id`, `version`, названием, неделей, днём, словарём, падежами и блоками заданий. Новый объект появится в выборе занятий. При изменении заданий уже опубликованного занятия увеличивайте `version`: это сохраняет старый черновик под отдельным ключом. Не меняйте идентификаторы и версии опубликованных попыток задним числом.

Схема первого занятия служит примером. Проверочные ключи в локальном `materials/` отделены от сайта и не публикуются в репозитории; ответов к контекстным заданиям в браузерных данных нет. Памятка содержит учебный образец склонения. Упражнения среды и пятницы нужно подготовить по результатам понедельника, затем добавить в каталог.

## Публикация

GitHub Pages публикует только каталог `docs/` из ветки `main`. Новые изменения в нём автоматически обновляют сайт после push в `main`. В настройках репозитория Pages выбран источник Deploy from a branch, ветка main, папка /docs. `.nojekyll` отключает обработку Jekyll — сборка приложения не нужна.

Локальный просмотр: запустить `python3 -m http.server 8765 --directory docs`, открыть `http://localhost:8765`. Не открывать HTML напрямую как файл: хранение в браузере и загрузка JSON требуют HTTP.

## Ответы и проверка

Экспорт содержит тему, версию задания, исходные ответы по номерам, выбранные падежи, подсказки, сомнения, причины исправлений и заметки ученицы. `evaluation` остаётся `null` до проверки. Время означает длительность открытой страницы, включая паузы. Файлы ответов и проверки хранить в игнорируемом каталоге `results/`, а не в публичном репозитории.
