# Литовский язык — практика грамматики

Личный учебный сайт. Первая тема: регулярные существительные на `-as` в единственном числе, все семь падежей. Задания и названия падежей на русском и литовском.

## Работа с сайтом

Ответы автоматически сохраняются в браузере. После завершения нажмите «Завершить и проверить»: оценка и разбор появляются сразу. Файл скачивается только по желанию. История завершённых попыток позволяет повторно скачать ответы. Новая попытка не меняет предыдущую. Во время занятия счётчик показывает заполнение. В отчёте отдельно оцениваются формы и выбранные падежи. Данные не отправляются на сервер. При очистке данных браузера или смене устройства локальная история недоступна — сохраняйте скачанные файлы.

## Добавление занятий

`docs/lessons.json` содержит массив `lessons`. Добавляйте новый объект с уникальным `id`, `version`, названием, неделей, днём, словарём, падежами и блоками заданий. Новый объект появится в выборе занятий. При изменении заданий уже опубликованного занятия увеличивайте `version`: это сохраняет старый черновик под отдельным ключом. Не меняйте идентификаторы и версии опубликованных попыток задним числом.

Каждое занятие содержит `sections`: `reference` с учебными моделями, `table` с идентификаторами клеток или `questions`. У задания указаны `id`, `word`, `number` (sg/pl), `model`, `chooseCase`; для заданного падежа — `case`, для контекста — `sentence` и перевод. Контекстные задания не показывают ответы до завершения; проверочные ключи загружаются браузером отдельно. Идентификаторы, версия и содержимое заданий понедельника сохранены; изменён только интерфейс и способ описания блоков. Для автоматической проверки на сайте опубликован `docs/answer-keys.json` с ответами и пояснениями; это обычный учебный сайт с доступными ключами, без защиты от просмотра исходников. Исходные материалы и личные результаты остаются в игнорируемых каталогах. Памятка содержит учебный образец склонения. Вторник: множественное число -as и повторение единственного. Среда: оба числа -as и отдельное введение -a единственного числа (V., K., G., Vt.). Четверг: полная модель -a единственного числа, семь падежей (52 ответа, ориентир 60 минут). Пятница: полная модель -a множественного числа, семь падежей, повторение -as и упражнение по комиксу (66 ответов, ориентир 75 минут). Следующие занятия готовятся по результатам.

## Публикация

GitHub Pages публикует только каталог `docs/` из ветки `main`. Новые изменения в нём автоматически обновляют сайт после push в `main`. В настройках репозитория Pages выбран источник Deploy from a branch, ветка main, папка /docs. `.nojekyll` отключает обработку Jekyll — сборка приложения не нужна.

Локальный просмотр: запустить `python3 -m http.server 8765 --directory docs`, открыть `http://localhost:8765`. Не открывать HTML напрямую как файл: хранение в браузере и загрузка JSON требуют HTTP.

## Ответы и проверка

Новый экспорт schemaVersion 3 содержит тему, версию задания, инструкции, исходные ответы по номерам, выбранные падежи, число и модель склонения. Чекбоксов, объяснений и самооценки нет. Ранее завершённые попытки schemaVersion 1 и 2 сохраняются без изменений. Для них отчёт вычисляется по соответствующему ключу без изменения сохранённого оригинала. Новые завершённые попытки содержат `evaluation`, а черновики — `evaluation: null`. Скачиваемый отчёт старой попытки — копия с добавленной оценкой, оригинал в истории не переписывается. Время означает длительность открытой страницы, включая паузы. Файлы ответов и проверки хранить в игнорируемом каталоге `results/`, а не в публичном репозитории.

## Варианты упражнений

`options` у вопроса заменяет свободный ввод выбором формы, сохраняя обычное поле `value` в экспорте. Блок `picture` содержит `image` (`src`, `alt`, `description`) и вопросы с `wordOptions`, `panel`; для таких вопросов `word` равен null, потому что нужное слово определяется по картинке. Экспорт сохраняет варианты слов, кадр и текстовое описание сцены для последующей проверки. Иллюстрация находится в `docs/assets/friday-comic.png`; её можно открыть крупнее. Текстовая альтернатива доступна отдельно.

Новые темы представляются полной регулярной моделью во всех семи падежах. Единственное и множественное число изучаются в отдельных занятиях. Старые уроки и их идентификаторы не меняются. Памятки не охватывают исключения и ударение.

## Автоматическая оценка и повторение

`docs/grading.js` — независимая проверка по ключу точной версии занятия. Нормализация: Unicode NFC, пробелы по краям и регистр; литовские буквы не заменяются обычными. Пропуски считаются ошибками. Для выбранных падежей знаменатель включает все задания, где выбор нужен.

Пояснение состоит из заранее проверенного правила для задания и требуемого окончания. Если ответ точно совпадает с другой формой того же слова или с формой другого известного слова, это отмечается. Для y/i и диакритики есть точные подсказки. Для произвольного неправильного ответа даётся правильный образец и правило; причина ошибки не угадывается.

Первоначальная попытка неизменна. «Повторить ошибки» создаёт отдельные раунды: сначала все ошибки и пропуски, затем только оставшиеся. Состояние сохраняется под `lt-grammar:practice:<sourceAttemptId>:v1`; указатель активного повторения — под ключом урока. Каждый раунд содержит ответы и отдельную оценку. Новая полная попытка отключает активное повторение; старые раунды остаются доступны в истории.

«Скопировать краткий отчёт» позволяет переслать текст; если буфер обмена недоступен, есть скачивание TXT. «Скачать ответы и оценку» сохраняет исходные ответы, оценку и раунды повторения. «Скачать все результаты» экспортирует файл `lt-grammar-results-bundle` из истории этого браузера. Синхронизации устройств и передачи данных на сервер нет.

Ключи собираются `python3 scripts/build_answer_keys.py` из проверенных локальных материалов. При новом уроке подготовьте ключ точной версии и правило выбора падежа для каждого задания, затем обновите каталог и ключи вместе. Для сохранённых старых версий сохраняйте соответствующие опубликованные ключи. Изменение ключа отмечается его `revision`, изменение алгоритма — `evaluatorVersion`; сохранённые оценки не переписываются.

Проверка алгоритма: `node --test tests/grading.test.cjs`. В ходе внедрения дополнительно сверены реальные выгрузки первых трёх уроков и браузерные сценарии отчёта, повторения, перезагрузки и экспорта.
